Publication controls

Published records should carry source, source URL, source publication/as-of date, retrieval timestamp, validation state and transformation notes. Missing data is preserved as missing rather than silently converted to zero.

Security model

No credentials, API keys or secrets are stored in public client-side files. External links use noopener noreferrer. IP-country detection is opt-in and the project does not store the returned IP.

Automated refresh

GitHub Actions performs scheduled source checks. A failed upstream fetch must not overwrite the last trusted snapshot. Source-specific parsers must pass validation before automated publication.

Responsible use

This project is an information and visualization layer, not an official surveillance system, medical service or travel authority. Always verify urgent decisions with the linked primary authority.
